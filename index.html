TREE(3): 20 Example Valid Trees

This page provides a small educational sample of valid trees used in TREE(3). It does not attempt to list all valid trees.

Notation

  • a = single-node tree with root label a
  • a(x) = root a with one child subtree x
  • a(x,y) = root a with two child subtrees x and y
